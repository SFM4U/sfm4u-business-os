# License and dependencies

SFM4U Wholesale source is GPL-2.0-or-later; see COPYING. This archive contains the SFM4U wholesale, B2B Pro, inventory bridge and POS source modules. “Pro” names a module, not a bundled commercial third-party plugin.

WordPress and WooCommerce are external required runtime dependencies and are not distributed in this archive. Dokan Lite is an optional external marketplace dependency. Public-profile plugin version tests do not grant redistribution rights and no third-party plugin/theme assets are bundled. PHP, database server, fonts, browser and hardware are supplied by the operator.

EAN-13 checksum/module encoding and integer cost allocation in this repository are original implementations; no barcode library is bundled. Barcode rendering does not allocate a GS1 identifier or certify a printer. No payment SDK or fiscal-device library is bundled.

Local development tooling and synthetic test fixtures are excluded from this installable archive. The release checklist and evidence in the source repository identify tested versions and remaining owner acceptance.
